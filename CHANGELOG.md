# Changelog

All notable changes will be recorded here when versioned releases begin. This repository is currently **early-access public source**, with no tagged production release.

## Unreleased: standalone migration (November 2026)

- Extracted Developer World from the prototype in GitHub Activity Studio into its own canonical repository.
- Preserved original archipelago and village renderer, day inspector, no-dependency GIF89a encoder and both palettes.
- Retained truthful GitHub GraphQL calendar collection and intentionally partial public REST decorations.
- Removed hard-coded maintainer username from collection and publishing logic.
- Added standalone scripts, Windows/Linux CI, safe daily/manual refresh automation, and deterministic demo fixtures.
- Migrated existing real-account SVG example images and clearly labelled synthetic samples; real GIF is regenerated by the new refresh workflow.
- Added open-source public documentation, agent instructions, security/contribution policy and MIT licence.
- Known visual issue remains: low versus high contribution days require stronger silhouette and density differences.

## Background

The original project was developed on \`concept/developer-world\` in https://github.com/AdityaSreevatsaK/GitHub-Activity-Studio. Historical discussion is in its draft PR #2. This standalone project is now the canonical codebase, without migrating unrelated Studio experiments.
