# Code of conduct

Developer World aims to be a welcoming technical community. Contributors, maintainers, reviewers and users are expected to keep discussion respectful, constructive and focused on code, design and evidence.

## Expected conduct

- Be respectful across backgrounds, skill levels and communication styles.
- Offer practical, actionable criticism of ideas and code rather than personal attacks.
- Credit original work and respect licences, data privacy and other people's time.
- Assume honest mistakes are possible and correct errors with evidence.
- Keep public feedback appropriate for an open, global audience.

## Unacceptable conduct

Harassment, discriminatory language, threats, insults, stalking, unwanted personal contact, deliberate disruption, disclosure of private information without permission, spam and knowingly misleading statements about contributors or GitHub activity are unacceptable.

## Reporting and enforcement

For public project issues, open a concise issue or notify the maintainer through an existing repository discussion. If a conduct incident involves private information, use GitHub's private reporting mechanisms if available, or request a private contact route **without describing sensitive details publicly**.

Maintainers may edit or remove inappropriate comments, warn participants, temporarily restrict engagement or block accounts when appropriate. Reports will be handled with discretion as capabilities allow. This project does not guarantee a formal response-time SLA.

This policy applies in this repository's issues, pull requests, reviews, discussions, public community spaces and direct project-related interactions. It may be updated as the community develops.
